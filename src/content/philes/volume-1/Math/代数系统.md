# 代数系统全套证明性质整理（分模块，附证明目标+判定条件，专治无从下手）
## 一、基础：集合上二元运算的性质（看到*、∘运算先判断这8条）
设$<S,*>$为代数系统，$\forall x,y,z\in S$
1. **封闭性**
   要证：$\forall x,y\in S,\ x*y\in S$
   用途：判断子集能否构成子代数/子群；有限群证子群核心前提
2. **交换律**
   要证：$\forall x,y\in S,\ x*y = y*x$
   满足则称*可交换；交换群（Abel群）必须证这条
3. **结合律**
   要证：$\forall x,y,z\in S,\ (x*y)*z = x*(y*z)$
   群、半群、独异点必备；证明直接左右展开化简相等
4. **幂等律**
   要证：$\forall x\in S,\ x*x = x$
   格、布尔代数典型性质
5. **吸收律（必须两个运算*、∨）**
   要证：$\forall x,y,\ x*(x\lor y)=x,\ x\lor(x*y)=x$
   仅格、分配格会用到
6. **分配律（两个运算）**
   左分配：$x*(y\lor z)=(x*y)\lor(x*z)$
   右分配：$(y\lor z)*x=(y*x)\lor(z*x)$
   环、布尔代数、分配格必考
7. **消去律**
   左消去：若$x*y=x*z$，则$y=z$
   右消去：若$y*x=z*x$，则$y=z$
   无零因子环、整环、有限独异点常用
8. **德摩根律（带补运算，布尔代数）**
   $\overline{x*y}=\overline{x}\lor\overline{y},\ \overline{x\lor y}=\overline{x}*\overline{y}$

## 二、特殊元素存在性证明（必考：单位元、零元、逆元、幂等元）
### 1. 单位元（幺元$e$）
**左单位元**：$\forall x,\ e_l*x=x$
**右单位元**：$\forall x,\ x*e_r=x$
**证明目标**：找到$e$同时满足左右，且唯一；
群、独异点必须存在单位元。
### 2. 零元$\theta$
左零元：$\forall x,\ \theta_l*x=\theta_l$
右零元：$\forall x,\ x*\theta_r=\theta_r$
证明目标：找到同时满足左右的唯一元素；环会用到零元。
### 3. 逆元（仅存在单位元时才有）
对元素$a$，找$b$满足：$a*b=e$（右逆），$b*a=e$（左逆）；
若左右逆相等，则$b=a^{-1}$，称$a$可逆。
**群核心条件：每个元素都存在唯一逆元**
### 4. 幂等元
满足$a*a=a$的元素，格中所有元素都是幂等元。

## 三、半群 / 独异点 / 群 / Abel群（最常考证明体系，分层记忆）
### 1. 半群 $<S,*>$
只需证明2条：
① 运算*在$S$封闭；② *满足结合律
### 2. 独异点（含幺半群）
半群 + ③ 存在单位元$e\in S$
### 3. 群$<G,*>$（4条定义，证明必须全覆盖）
1. 封闭：$\forall a,b\in G,\ ab\in G$
2. 结合律：$(ab)c=a(bc)$
3. 存在单位元$e$：$\forall a,\ ea=ae=a$
4. 每个元有逆元：$\forall a,\exists a^{-1},\ aa^{-1}=a^{-1}a=e$

#### 群简化判定定理（做题优先用，少证步骤）
1. **单边判定**：非空有限集$G$封闭+结合律$\implies G$是群（你之前那道题就是这个）
2. **子群判定1（通用）**：$H\subseteq G$非空，$\forall a,b\in H,\ ab^{-1}\in H \implies H$子群
3. **子群判定2（有限子集）**：$H$有限非空、运算封闭$\implies H$子群

### 4. Abel群（交换群）
群全部4条 + 交换律$ab=ba$

### 群衍生证明题型对应性质
- 证群阶$|G|$：拉格朗日定理（子群阶整除群阶）
- 证元素阶：$a^k=e$最小正整数$k$；有限群元素阶整除群阶
- 证正规子群：$\forall g\in G,h\in H,\ ghg^{-1}\in H$

## 四、环 / 整环 / 域（两个运算$+$加法，$\cdot$乘法）
### 1. 环$<R,+,·>$，分两部分证明
1. $<R,+>$是**交换群**（加法Abel群）：封闭、结合、单位元0、负元、交换
2. $<R,·>$是**半群**：乘法封闭、乘法结合律
3. 乘法对加法分配律：$a·(b+c)=a·b+a·c,\ (b+c)·a=b·a+c·a$

### 2. 含幺环
环 + 乘法存在单位元$1$
### 3. 交换环
环 + 乘法交换律$a·b=b·a$
### 4. 整环（无零因子交换含幺环）
交换含幺环 + **无零因子**（消去律成立：$ab=0\Rightarrow a=0$或$b=0$）
### 5. 域
整环 + 每个非0元乘法可逆（非零元全体构成乘法Abel群）

## 五、格 / 分配格 / 布尔代数（偏序+两个运算∧、∨）
### 1. 格$<L,\land,\lor>$
两种证明路径：
1. 偏序路径：任意两个元素存在上确界∨、下确界∧
2. 运算公理路径：同时满足交换律、结合律、吸收律、幂等律
### 2. 分配格
格 + 乘法分配律 $a\land(b\lor c)=(a\land b)\lor(a\land c)$
### 3. 有补格
有界格（存在最大元1、最小元0）+ $\forall x,\exists \overline{x}$，$x\land\overline{x}=0,\ x\lor\overline{x}=1$
### 4. 布尔代数
有补分配格（分配律+补元存在），额外满足德摩根律

## 六、同态、同构、同余关系（映射类证明）
设$f:A\to B$，$A,B$是同类型代数系统，运算均为*
1. **同态映射**
   证明目标：$\forall x,y\in A,\ f(x*_A y)=f(x)*_B f(y)$（保运算）
   细分：单同态（单射）、满同态（满射）
2. **同构映射**
   同态 + 双射（单射+满射），两个代数系统结构完全相同
3. **同余关系$R$（等价关系+保运算）**
   两步证明：
   ① $R$是等价关系：自反、对称、传递
   ② 保运算：若$xRy,\ uRv$，则$(x*u)R(y*v)$
   用途：构造商代数$A/R$

---
## 七、等价关系 / 偏序关系（集合二元关系证明，代数前置基础）
### 1. 等价关系（证3条）
1. 自反：$\forall x,\ xRx$
2. 对称：若$xRy$则$yRx$
3. 传递：若$xRy,yRz$则$xRz$
### 2. 偏序关系（证3条）
1. 自反、2. 反对称（$xRy,yRx\Rightarrow x=y$）、3. 传递
### 3. 全序（线序）
偏序 + 任意两元素可比：$\forall x,y,\ xRy$或$yRx$

# 做题通用思路（解决“不知道要证什么”）
1. **先看题目要求证明的结构**
   例：证$H$是子群 → 直接对照群4条/子群判定定理；证是环 → 先证加法交换群，再证乘法半群+分配律
2. **拆分目标，逐条列需要验证的性质**
   比如证布尔代数，直接列清单：交换、结合、吸收、分配、有界、补元存在，一条一条证
3. **区分“有限/无限”**
   有限集优先用简化判定（有限子集封闭即子群）；无限必须证逆元、单位元
4. **映射题只抓核心：保运算**
   同态、同构所有证明起点都是$f(xy)=f(x)f(y)$，再附加单/满射
