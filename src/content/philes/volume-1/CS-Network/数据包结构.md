# 二、第一张图：TCP头部完整字段释义（传输层）
## 逐行字段（从上至下）
1. Source port（源端口，16bit）：发送进程端口号
2. Destination port（目的端口，16bit）：接收进程端口号
3. Sequence number（序列号，32bit）：本报文数据第一个字节编号
4. Acknowledgement number（确认号，32bit）：期望收到下一字节序号
5. 第四行拆分：
   - TCP header length（数据偏移，4bit）：TCP头部长度，单位4字节，最小5（20B），最大15（60B）
   - 保留位（灰色空白，6bit）：固定0
   - 6位控制标志（从左到右）：
     CWR：拥塞窗口减小；ECE：显式拥塞通知；URG：紧急指针有效；ACK：确认号有效；PSH：推送；RST：重置连接；SYN：同步握手；FIN：结束连接
   - Window size（窗口大小，16bit）：接收方缓冲区剩余容量（流量控制rwnd）
6. Checksum（校验和，16bit）：校验TCP头+数据+伪首部
7. Urgent pointer（紧急指针，16bit）：URG=1时，标识紧急数据末尾偏移
8. Options（可选选项，32bit字对齐）：窗口缩放、MSS、时间戳等
9. Data（可选数据）：上层应用载荷

# 三、第二张图：IP头部完整字段释义（网络层）
## 逐行字段（从上至下）
1. Version（版本，4bit）：4=IPv4，6=IPv6
2. IHL（首部长度，4bit）：IP头长度，单位4字节，最小5(20B)
3. Differentiated Services（DS区分服务，8bit）：QoS优先级
4. Total length（总长度，16bit）：整个IP报文（头+数据）字节数，最大1500
5. Identification（标识，16bit）：同一原始报文所有分片共用此值，用于重组分片
6. 标志位（3bit）：
   DF：不分片；MF：More Fragment，MF=0代表最后一片分片
7. Fragment offset（片偏移，13bit）：分片数据在原始报文的偏移位置（单位8字节）
8. Time to live（TTL生存时间，8bit）：每过一台路由器-1，0则丢弃报文
9. Protocol（协议，8bit）：IP内部上层协议编号（重点对照表见上方）
10. Header checksum（首部校验和，16bit）：仅校验IP头部
11. Source address（源IP，32bit）：发送主机IP地址
12. Destination address（目的IP，32bit）：接收主机IP地址
13. Options（IP可选选项）：路由记录、时间戳等，无则省略

# 四、第三张图：以太网帧完整字段释义（数据链路层）
## 从左到右所有字段
1. 报头(8字节)：前导码+帧起始符，同步时钟，接收端识别帧开始
2. 目标地址(6字节)：下一跳设备MAC地址
3. 源地址(6字节)：本机出接口MAC地址
4. 以太类型(2字节)：区分内部三层报文类型（重点对照表见上方）
5. 有效负载(46~1500字节)：完整IP数据报（第二张IP头整张内容都在这里）
6. 填充(0+字节)：当IP报文长度＜46字节时补0，补齐46字节；IP报文≥46字节时填充段为空
7. 校验(4字节FCS)：帧CRC校验，检测传输比特错误

# 五、核心协议编号汇总背诵表
## 1）以太网「以太类型」二层类型码（第三张图）
| 十六进制值 | 承载协议 |
| ---- | ---- |
| 0x0800 | IPv4 |
| 0x0806 | ARP |
| 0x86DD | IPv6 |

## 2）IP头部「Protocol」传输层协议号（第二张图）
| 十进制值 | 协议 |
| ---- | ---- |
| 1 | ICMP（网络层差错报文） |
| 6 | TCP（面向连接可靠传输） |
| 17 | UDP（无连接快速传输） |
| 2 | IGMP（组播管理） |
