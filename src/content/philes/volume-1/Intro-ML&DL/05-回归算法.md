# 05 回归算法

> 来源：黑马《机器学习宝典》
> 重点：线性回归及其正则化变体，理解「最小二乘 → 闭式解 / 梯度下降」。

## 5.1 线性回归（Linear Regression）

- 假设：$h_\theta(\mathbf{x})=\mathbf{w}^T\mathbf{x}+b$。
- 目标：最小化 **均方误差 MSE**（等价于极大似然假设高斯噪声）：
  $$J(\mathbf{w})=\frac{1}{2m}\sum_{i=1}^m(\mathbf{w}^T\mathbf{x}^{(i)}+b-y^{(i)})^2$$

### 求解方式
1. **正规方程（闭式解）**：
   $$\mathbf{w}^*=(X^T X)^{-1}X^T\mathbf{y}$$
   直接解，但 $X^T X$ 求逆 $O(n^3)$，特征多（>1e4）或共线性时不稳定。
2. **梯度下降**（更通用，也适用于不可解析的模型）：
   $$\mathbf{w}:=\mathbf{w}-\alpha\frac{1}{m}X^T(X\mathbf{w}-\mathbf{y})$$

- 线性回归假设：特征与目标线性相关、误差独立同分布高斯、无多重共线性。

## 5.2 正则化线性模型

### 岭回归（Ridge / L2）
$$J(\mathbf{w})=\text{MSE}+\lambda\|\mathbf{w}\|_2^2$$
- 让 $\mathbf{w}$ 整体变小，缓解共线性、降方差；**不稀疏**（权重趋近 0 但不等于 0）。
- 闭式解：$\mathbf{w}^*=(X^TX+\lambda I)^{-1}X^T\mathbf{y}$（加 $\lambda I$ 保证可逆）。

### Lasso 回归（L1）
$$J(\mathbf{w})=\text{MSE}+\lambda\|\mathbf{w}\|_1$$
- 产生**稀疏解**（部分 $\mathbf{w}=0$），自带特征选择；非处处可微，用坐标下降等求解。

### 弹性网络（Elastic Net）
$$J=\text{MSE}+\lambda_1\|\mathbf{w}\|_1+\lambda_2\|\mathbf{w}\|_2^2$$
- Lasso 与 Ridge 折中，特征数 >> 样本时更稳。

## 5.3 评估与诊断

- 看残差图：残差应随机分布在 0 附近；若出现 U 形说明模型欠拟合（非线性）。
- 多重共线性检测：VIF（方差膨胀因子）>10 一般视为严重。
- 用 `04` 的 RMSE/MAE/$R^2$ 评估。
