# "AI 弃子"CPU 逆风翻盘：英特尔、AMD 与 ARM 意料之外的一场胜利

> **播客：** 硅谷 101 | **主播：** 泓君 Jane | **日期：** 2026 年 5 月
> **嘉宾：** Rob Li（纽约 Amont Partners 管理合伙人），Gary Ge Wang（华美半导体协会主席）
> **时长：** 约 30 分钟（B 站视频）

---

## 节目概要

当全球 AI 投资的目光都聚焦在 GPU 上时，CPU——这个曾被戏称为"AI 弃子"的芯片品类——正在悄然上演一场出人意料的逆风翻盘。英特尔、AMD、Arm 三家 CPU 巨头接连交出爆炸性财报：英特尔股价单日暴涨 24%，创下 40 年来最大单日涨幅；AMD 数据中心营收同比增长 57%，总营收首次突破 100 亿美元；Arm 的 AGI CPU 已经拿下超过 20 亿美元预订单。CPU 为什么突然"香"了？本期节目从两个关键驱动力切入——Agent 爆发和超长上下文窗口——深度解析 CPU 逆袭背后的产业逻辑、供需格局变化以及未来市场走向。

嘉宾指出，CPU 的 GPU 配比正在发生根本性转变：从传统的 1:4 甚至 1:8，转向 1:1 甚至 1:2。这意味着每部署一颗 GPU，就需要配套接近一颗 CPU，CPU 的需求量正在被结构性重估。但供给端却面临严峻挑战：台积电产能被利润更高的 GPU 订单挤占，英特尔 18A 良率仍在爬坡，ABF 载板供应短缺——CPU 短缺预计将持续到 2027 年底。

## 核心观点

### 1. CPU 三巨头齐发爆炸财报

- **英特尔 Q1 2026：** 营收 136 亿美元，其中 DCAI（数据中心与 AI）业务营收 51 亿美元，同比+22%；股价单日暴涨 24%，创 40 年最大单日涨幅
- **AMD：** 数据中心营收同比+57%，总营收首次突破 100 亿美元大关；将 2030 年服务器 CPU TAM 从 600 亿美元上调至 1200 亿美元，直接翻倍
- **Arm：** AGI CPU 采用台积电 3nm 工艺，已获超 20 亿美元预订单；Arm 架构在服务器市场的渗透率持续攀升
- 三家公司财报后股价集体大涨，市场对 CPU 的认知正在被重新定价——从"增长停滞的夕阳业务"到"AI 基础设施的关键支柱"

### 2. 驱动力一：Agent 爆发——CPU 是 Agent 的"大脑"

- 当 AI Agent 在高性能 GPU 上运行时，**65%的延迟来自 CPU 端**，而非 GPU 端
- Agent 的核心工作负载——任务编排（orchestration）、工具调用（tool calling）、代码执行（code execution）——天然属于 CPU 密集型任务
- GPU 擅长的是模型推理（单次前向传播），但 Agent 的"思考-行动-观察"循环需要在 CPU 上运行大量逻辑判断、上下文管理和函数调用
- 一个 Agent 在处理复杂任务时，可能在 GPU 上只跑几十毫秒的推理，但 CPU 上需要几百毫秒甚至更长的编排逻辑
- 这意味着：Agent 越普及，CPU 的需求就越强劲——Agent 的"思考过程"本质上是 CPU 负载

### 3. 驱动力二：超长上下文窗口——GPU 显存溢出，CPU 兜底

- 百万 token 级别的上下文窗口正在成为大模型标配，但这也带来了巨大的显存压力
- 当上下文长度超出 GPU HBM 显存容量时，KV Cache（键值缓存）需要溢出到 CPU 内存
- CPU 内存容量远大于 GPU 显存（TB 级 vs GB 级），成本也更低，是超长上下文的"天然承载者"
- 超长上下文推理场景下，CPU 承担了大量 KV Cache 的存取和管理工作，成为系统性能的关键瓶颈
- 这一趋势意味着：模型上下文越长，CPU 在推理基础设施中的战略地位越重要

### 4. CPU:GPU 配比的结构性转变

- **传统配比：** 1:4 到 1:8（一台服务器 8 个 GPU 配 1-2 个 CPU），CPU 是"配角"
- **新配比：** 1:1 到 1:2（每 1-2 个 GPU 就需要配 1 个 CPU），CPU 升级为"必要搭档"
- 这一转变的根本原因：Agent 工作负载和超长上下文推理改变了 CPU 在 AI 系统中的角色——从"辅助管理"到"核心计算"
- 对数据中心架构的影响：服务器设计需要重新平衡 CPU 与 GPU 的资源配置，传统以 GPU 为中心的架构面临调整
- 对 CPU 厂商的意义：英特尔、AMD、Arm 的服务器 CPU 业务将迎来结构性增长，不再是"GPU 热潮的旁观者"

### 5. 供给端三重瓶颈：台积电、英特尔 18A、ABF 载板

- **台积电产能挤压：** 台积电 2026-2027 年产能已售罄，GPU 等高利润产品优先排产，CPU 产能被挤占
- **英特尔 18A 良率问题：** 英特尔最新的 18A 制程良率仍在 30-50%之间爬坡，远未达到量产经济性要求
- **ABF 载板短缺：** CPU 封装所需的 ABF（Ajinomoto Build-up Film）载板供应持续紧张，扩产周期长（通常 18-24 个月）
- 三重瓶颈叠加，CPU 供应短缺预计将持续到 2027 年底
- CPU 价格已上涨 30%，交货周期从 1-2 周延长至 8-12 周

### 6. NVIDIA 的反向布局：推出独立 Vera CPU

- NVIDIA 正在推出独立 Vera CPU，专门面向 Agent 工作负载——印证了 CPU 在 AI 生态中的战略价值
- Vera CPU 的定位不是替代 Grace（NVIDIA 的 Arm 架构 CPU），而是作为独立产品线切入 Agent 推理市场
- NVIDIA 的入局意味着：即便是 GPU 霸主，也看到了 CPU 在 AI 时代不可替代的价值
- 这一布局可能重塑 CPU 市场格局：传统 CPU 厂商面临来自 NVIDIA 的跨界竞争

### 7. CPU 市场的三层架构

- **第一层：头节点 CPU（Head Node CPU）**——负责 AI 训练/推理集群的调度管理，高核心数、高内存带宽
- **第二层：独立 CPU 机架（Standalone CPU Racks）**——专门为 Agent 工作负载、超长上下文推理部署的纯 CPU 计算集群
- **第三层：PC/边缘 CPU**——AI PC 和边缘 AI 设备对本地推理能力的需求，推动消费级 CPU 升级换代
- 每一层都有不同的性能需求和竞争格局，CPU 市场正在从"同质化的大饼"变成"三层蛋糕"

## 关键洞察

> "CPU 不是被 AI 时代抛弃了，而是被 AI 时代重新定义了。当 Agent 成为 AI 应用的主流形态，CPU 就不再是 GPU 的配角，而是 AI 推理链条中不可或缺的一环。"

> "65%的延迟来自 CPU——这个数字颠覆了很多人的认知。大家以为 AI 就是 GPU 的事，但实际上 Agent 的'思考'过程发生在 CPU 上。GPU 只是'嘴'，CPU 才是'大脑'。"

> "英特尔股价单日涨 24%，这是市场用真金白银投票：CPU 在 AI 时代的故事远没有结束，恰恰相反，好戏才刚刚开始。"
